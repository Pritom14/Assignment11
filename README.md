# Assignment11

- `EleventhAssignment/` — Android Studio/Gradle project root, including the Gradle wrapper and build configuration.
- `EleventhAssignment/app/src/main/java/` — Java source code (e.g. `MainActivity.java`).
- `EleventhAssignment/app/src/main/res/` — Android resources (layouts, values, mipmaps) and `AndroidManifest.xml`.
